circuito:
1. ejecutivo de cuentas recibe las listas de precios de cada proveedor
2. ejecutivo de cuentas consolida las listas de precios en una sola
3. esa lista unica es presentada a cada socio para que este pueda elegir por proveedor los productos que quiere
4. estos pedidos son recibidos por el ejecutivo de cuentas y envia los pedidos a cada proveedor
5. una vez que llega el pedido del proveedor el ejecutivo de cuentas lo registra en el sistema y hace el reparto automatico segun lo que pidio cada socio
